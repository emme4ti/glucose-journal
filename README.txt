ГЛЮКОДНЕВНИК — v2.0, IndexedDB

УСТАНОВКА НА GITHUB PAGES
1. Распакуй ZIP. В своём существующем репозитории GitHub загрузи файлы index.html, service-worker.js, manifest.webmanifest, icon-180.png, icon-512.png прямо в корень, заменив старые одноимённые файлы (или загрузи папку через Git).
2. Не меняй название репозитория/URL. На iPhone открой уже добавленное на экран Домой приложение. Иногда нужно закрыть и снова открыть его 1–2 раза после публикации, чтобы обновился service worker. НЕ удаляй иконку и не очищай данные сайта.
3. Существующие записи из localStorage v1 автоматически переносятся в IndexedDB при первом открытии новой версии на ТОМ ЖЕ устройстве и в ТОМ ЖЕ установленном приложении. Не меняй домен.
4. Перед обновлением полезно скачать JSON через Экспорт → Полный JSON и сохранить в iCloud Drive — на всякий случай.

ЧТО НОВОГО
- Записи и показания CGM хранятся в IndexedDB; резервный режим localStorage, если IndexedDB не работает.
- Индикатор успешного сохранения либо ошибки после записи.
- Напоминание о резервном копировании через 3 дня после последней отмеченной копии или после появления данных при отсутствии копии.
- Экспорт полного JSON, отметка «Я сохранила файл», восстановление из старого JSON v1 и нового JSON v2.
- Новый service worker проверяет актуальный HTML в сети при запуске, но использует кэш офлайн.
- Сохранились все функции дневника, графиков CGM, CSV, ZIP.

ПРИВАТНОСТЬ И НАДЁЖНОСТЬ
Данные остаются локальными на конкретном устройстве/установленном приложении и не синхронизируются с GitHub. IndexedDB может быть очищена системой, пользователем или при удалении приложения; это НЕ замена резервной копии. Каждые 2–3 дня сохраняй JSON в iCloud Drive. Сохранение файла должен подтвердить пользователь: приложение не может проверить, что файл реально сохранён. Открытие в Safari и открытие с экрана Домой могут использовать разные хранилища.
Если видишь «Резервный режим localStorage», скачивай JSON особенно регулярно.
