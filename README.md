# Глюкодневник 2.1.0

Мобильный дневник питания и наблюдений за глюкозой (CGM). Работает как веб-приложение (PWA) на iPhone, iPad и других устройствах. Записи хранятся локально, без аккаунта и без отправки данных в GitHub.

## Установка и обновление через GitHub Pages

1. Распакуйте архив и загрузите файлы `index.html`, `service-worker.js`, `manifest.webmanifest`, `icon-180.png`, `icon-512.png` и `README.md` **в корень репозитория**. При обновлении замените одноимённые файлы.
2. Для первого развёртывания откройте в репозитории **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, затем `main` и `/(root)` и сохраните настройки.
3. Откройте опубликованный адрес вида `https://<username>.github.io/<repository>/` в Safari на iPhone, затем выберите **Поделиться → На экран «Домой»**.
4. Если вы **обновляете уже установленное приложение**, **не меняйте URL**, не удаляйте иконку с домашнего экрана и не очищайте данные сайта. После публикации может потребоваться закрыть и снова открыть приложение, чтобы обновился service worker.

> **Как проверить обновление:** откройте приложение с той же иконки на домашнем экране и посмотрите на номер **v2.1.0** рядом с заголовком. Если отображается старый номер, закройте приложение полностью, подключитесь к сети и откройте ещё раз. При необходимости повторите после нескольких секунд. Не удаляйте иконку: это может удалить локальные записи.

> **Перед обновлением:** откройте старую версию, выберите **Экспорт → Полный JSON** и сохраните резервную копию в iCloud Drive.

## Возможности

- Дневник питания, активности, сна и самочувствия.
- Импорт CSV с показаниями монитора глюкозы (CGM).
- Графики глюкозы и просмотр реакции после еды.
- Экспорт данных для анализа: CSV/ZIP и полная резервная копия JSON.
- Восстановление из JSON, созданного в версии 1 или 2.
- Офлайн-работа после первоначальной загрузки приложения.

## Что изменилось в версии 2.1.0

- Номер версии **v2.1.0** постоянно виден рядом с названием «Глюкодневник» на главном экране, в том числе в режиме приложения на iPhone.
- Версия также отображается в заголовке вкладки браузера и записывается в JSON-экспорт (поле `app_version`).
- Обновлён кэш офлайн-приложения, чтобы новая версия могла загрузиться при следующем подключении к сети.

### Изменения версии 2.0

- **IndexedDB** вместо `localStorage` для хранения записей и показаний CGM. Если IndexedDB недоступна, включается резервный режим `localStorage`.
- Автоматический перенос записей из версии 1 в IndexedDB при первом запуске новой версии **на том же устройстве и в том же установленном приложении**.
- Индикатор успешного сохранения или ошибки записи.
- Напоминание о резервной копии через три дня после последней отмеченной копии (или после появления данных, если копии ещё не было).
- Отметка **«Я сохранила файл»** после экспорта JSON.
- Обновлённый service worker: проверка новой версии в сети с возможностью продолжать работу офлайн.

## Хранение данных и конфиденциальность

GitHub Pages публикует **код приложения**, а не содержимое дневника. Данные сохраняются локально на конкретном устройстве и не синхронизируются с GitHub или между устройствами. Версия в Safari и приложение с экрана «Домой» могут использовать разные хранилища.

**IndexedDB не является резервной копией.** Данные могут пропасть после удаления приложения, очистки данных сайта или вследствие действий системы. Сохраняйте **Полный JSON в iCloud Drive каждые 2–3 дня**. Приложение не может проверить, что экспортированный файл действительно остался в хранилище; пользователь подтверждает это вручную.

Если приложение показывает **«Резервный режим localStorage»**, делайте резервные копии особенно регулярно.
